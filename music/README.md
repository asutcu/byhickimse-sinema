# Telifsiz yerel muzik

Uzun form belgeseller burada duran ses dosyalarini arka plan muzigi olarak kullanir.

- YouTube Music kutuphanesi cekilmez.
- Desteklenen uzantilar: `.mp3` `.wav` `.m4a` `.aac` `.ogg` `.flac`
- Tur eslemesi icin dosya adina mood anahtari koyabilirsiniz: `dark-ambient`, `period-strings`, `sleep-drone`, `meditation`, `cinematic-soft`, `pulse-low`
- Proje ozel dosya: `projects/<slug>/longform/` icine de koyabilirsiniz.
